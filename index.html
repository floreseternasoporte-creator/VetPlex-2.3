Al publicar, los archivos se suben a tu bucket de AWS S3 y el catálogo se actualiza en toda la plataforma.

Conexión con AWS

Qué configurar en la consola de AWS

1) Lectura pública (política del bucket), para que los videos se vean sin login:

{
  "Version": "2012-10-17",
  "Statement": [{
    "Sid": "PublicRead",
    "Effect": "Allow",
    "Principal": "*",
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::vetplex-media-682849160982/*"
  }]
}

2) CORS del bucket (Permisos → CORS), para subir desde la web:

[{
  "AllowedHeaders": ["*"],
  "AllowedMethods": ["GET","PUT","POST","DELETE","HEAD"],
  "AllowedOrigins": ["https://floreseternasoporte-creator.github.io"],
  "ExposeHeaders": ["ETag"],
  "MaxAgeSeconds": 3000
}]

3) El usuario vetplex-uploader solo necesita: s3:PutObject, s3:GetObject, s3:DeleteObject, s3:ListBucket y s3:AbortMultipartUpload sobre este bucket.
